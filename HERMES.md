# pr-prep — Public Relations study app

Workdir `~/Code/pr-prep`. Fork engine relmat-prep. UTS bocoran: 25 PG + 4 essay (RJP, fear appeal, press release + 1 prediksi).
- Build: `uv run python build/parse.py` lalu `uv run python build/build.py`; deploy `bash build/deploy.sh` -> https://melvernmogens.github.io/pr-prep/
- Sumber PPTX di `sources/`, teks slide di `src_txt/w*.txt` (gitignore).
- Bot: content->W1+2, research->W3+4, analyst->W5+6, growth->essay UTS.
- @slide w4-06 = gambar slide asli (assets/slides), level topik dan contoh.

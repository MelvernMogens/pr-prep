@topic w1-def :: Apa itu Public Relations :: PR = komunikasi strategis buat bangun relasi saling menguntungkan antara organisasi dan stakeholder-nya.
@intro
- PR = strategic communication process yang bangun mutually beneficial relationships antara organisasi dan stakeholder-nya.
- Stakeholder-nya banyak: owners, management, employees, clients, customers/consumers, public, community, government, audience nasional/internasional.
- Advertising = jualan produk lewat paid media placement. Paling sempit.
- Marketing = create, communicate, deliver value produk. Lebih luas dari advertising.
- PR = broadest role: bangun + jaga bermacam relasi stakeholder dalam jangka panjang.
@concept w1-pr-def :: Public relations :: Strategic communication process yang membangun hubungan saling menguntungkan antara organisasi dan stakeholder-nya. Perannya paling luas: jaga relasi jangka panjang, bukan cuma jualan.
@concept w1-stakeholders :: Stakeholders :: Pihak-pihak yang relasinya dikelola PR: owners, management, employees, clients, customers/consumers, public, community, government, dan audience nasional/internasional.
@concept w1-advertising :: Advertising :: Peran spesifik yang fokus jualan produk lewat pemasangan media berbayar (paid media placement).
@concept w1-marketing :: Marketing :: Peran lebih luas dari advertising: menciptakan, mengomunikasikan, dan mengantarkan value produk ke pelanggan.
@trap PR = iklan :: Salah. Advertising cuma satu peran sempit (jualan lewat media berbayar). PR jangkauannya paling luas: relasi dengan SEMUA stakeholder, jangka panjang. Jangan jawab "PR itu bagian dari marketing" di ujian — slide bilang PR the broadest role.
@example Iklan, marketing, atau PR? :: Kasus latihan
@soal
Kopi Rakyat, merek kopi baru di Bandung, lagi jalanin tiga kegiatan:
• Bayar Rp40 juta buat iklan TV 30 detik di prime time.
• Riset rasa kopi + desain packaging biar pelanggan ngerasa dapet value.
• Rutin buka roastery buat komunitas sekitar + ketua RT + dinas pariwisata tiap kuartal.
(a) Klasifikasi tiap kegiatan: advertising, marketing, atau public relations.
(b) Kenapa PR disebut peran yang paling luas (broadest role)?
@step Cocokkan kegiatan dengan ciri tiap peran :: Kuncinya lihat ciri di definisi, bukan perasaan. Iklan TV = bayar media buat jualan → advertising. Rasa + packaging = create & deliver value → marketing. Komunitas + RT + dinas pariwisata = bangun relasi jangka panjang dengan public, community, dan government → PR.
| Kegiatan | Ciri di kasus | Peran |
| Iklan TV 30 detik | paid media placement | Advertising |
| Riset rasa + packaging | create, communicate, deliver value | Marketing |
| Komunitas + RT + dinas pariwisata | relasi jangka panjang multi-stakeholder | Public relations |
@step Uji dengan pertanyaan pembalik :: Kalau kegiatannya berhenti bayar media, apakah masih iklan? Kalau kegiatannya bukan soal produk sama sekali, apakah masih marketing? Kegiatan komunitas & pemerintah lolos dua tes itu → jelas PR.
@step Susun alasan (b) :: Advertising fokusnya sempit (jual produk via paid media). Marketing luas tapi masih soal value produk. PR hadapi bermacam-macam stakeholder dan untuk jangka panjang → makanya disebut broadest role yang develop dan preserve relasi.
@answer (a) Iklan TV = advertising; riset rasa + packaging = marketing; kegiatan komunitas + RT + dinas pariwisata = public relations. (b) PR paling luas karena mengelola hubungan dengan beragam stakeholder dalam jangka panjang, sementara advertising cuma jualan lewat paid media dan marketing masih terkunci di value produk.
@uses w1-pr-def, w1-advertising, w1-marketing, w1-stakeholders
@end

@topic w1-mbo :: Management by Objectives (MBO) :: Kerangka 6 tahap buat nyusun goals kampanye PR — dari conceptualization sampai evaluation.
@intro
- MBO = kerangka buat jawab "goal kampanye ini apa?".
- 6 tahap: conceptualization, monitoring, planning, organization and coordination, administration, evaluation.
- Conceptualization = ngidentifikasi tugas dan tanggung jawab.
- Monitoring = mengantisipasi + mengevaluasi tantangan/peluang.
- Planning = mastikan hasil yang relevant dan measurable.
- Organization and coordination = implementasi strategi secara efektif dan efisien.
- Administration = bikin langkah + budget + jadwal.
- Evaluation = tunjukkan accountability dan credibility, panduan sukses ke depan.
@concept w1-mbo :: Management by Objectives :: Kerangka 6 tahap untuk menyusun goals kampanye PR: conceptualization, monitoring, planning, organization and coordination, administration, evaluation.
@vars
Conceptualization :: mengidentifikasi tugas dan tanggung jawab
Monitoring :: mengantisipasi dan mengevaluasi tantangan/peluang
Planning :: memastikan pencapaian hasil yang relevant dan measurable
Organization and coordination :: mengimplementasikan strategi secara efektif dan efisien
Administration :: membuat langkah-langkah dengan budget dan jadwal
Evaluation :: menunjukkan accountability dan credibility untuk panduan sukses ke depan
@trap Evaluation = tahap terakhir yang nggak penting :: Salah. Evaluation = demonstrasi accountability dan credibility, hasilnya jadi guidance untuk kesuksesan kampanye berikutnya. Di kasus nyata (misal food poisoning), evaluation justru yang nyelametin reputasi jangka panjang.
@example Kampanye rumah sakit :: Slide W1 · Mini case
@soal
Kamu pegawai PR sebuah rumah sakit (slide W1):
• Pendapatan rumah sakit datang dari orang-orang yang lagi sakit.
• Kalau promosi gituan, kelihatan tamak (greedy) — makan untung dari kesialan orang.
• Budget promosi terbatas karena biaya operasional naik.
• Rumah sakit nggak mau kelihatan boros (wasteful).
(a) Kenapa rumah sakit nggak bisa ting-ting promosi seperti bisnis biasa?
(b) Susun goal kampanye dengan tahap MBO.
@step Pahami dulu posisi unik rumah sakit :: Revenue-nya dari orang yang kena bad news dan emergency. Iklan agresif = kelihatan greedy. Sekaligus budget-nya sempit = nggak boleh kelihatan wasteful. Dua belenggu ini yang bikin kampanye biasa gagal.
@step Conceptualization + monitoring :: Conceptualization: tugas kita = jaga reputasi + edukasi kesehatan, bukan dorong transaksi. Monitoring: peluang = isu kesehatan lagi ramai; ancaman = dibilang komersial dan boros; kalau dinas kesehatan diabaikan, izin bisa bermasalah.
@step Planning + organization and coordination :: Planning: goal harus relevant dan measurable — contoh: program cek kesehatan gratis 4 kali setahun, target 500 peserta per kota, nol biaya iklan berbayar. Organization and coordination: kerja sama dengan puskesmas dan komunitas, jalan efektif-efisien sesuai budget terbatas.
@step Administration + evaluation :: Administration: jadwal 4 kuartal, budget dari dana CSR, penanggung jawab per kota. Evaluation: ukur jumlah peserta, liputan media, dan survei persepsi warga — hasilnya jadi accountability dan panduan kuartal berikutnya.
@answer (a) Karena sumber pendapatannya dari orang sakit: promosi keras terkesan greedy, sementara pengeluaran besar terkesan wasteful — dua-duanya racun reputasi. (b) Goal lewat MBO: program pelayanan/edukasi kesehatan gratis yang measurable (contoh: 500 peserta per kota, 4 kali setahun), dijalankan efektif-efisien dengan mitra komunitas, dan dievaluasi untuk accountability serta perbaikan kampanye berikutnya.
@uses w1-mbo
@end
@example Food poisoning restoran Vietnam :: Slide W1 · Mini case
@soal
Januari 2020, 8 orang keracunan setelah makan di restoran Vietnam di Jakarta Barat (liputan The Jakarta Post). Kamu konsultan PR restoran itu.
(a) Jelaskan situasi ini dalam tahap conceptualization dan monitoring.
(b) Apa goal restoran pada kasus ini?
(c) Apa yang harus dilakukan manajemen?
@step Conceptualization — tugas dan tanggung jawab :: Tugas PR restoran = penanganan krisis kepercayaan: keselamatan pelanggan + reputasi restoran. Tanggung jawabnya jelas: komunikasi jujur soal kejadian, bukan tutup mata.
@step Monitoring — antisipasi tantangan/peluang :: Tantangan: liputan nasional (Jakarta Post), review buruk bisa muncul, dinkes bisa turun. Peluang: respons cepat dan transparan bisa dibalik jadi bukti restoran bertanggung jawab. Monitoring = pantau dua-duanya SEKARANG, bukan setelah viral.
@step Goal dan aksi manajemen :: Goal: pulihkan kepercayaan (bukan sales!). Manajemen: periksa kesehatan korban + tanggung biaya, koordinasi dengan dinas kesehatan, umumkan hasil investigasi dan perbaikan prosedur dapur, lalu evaluasi respons sebagai panduan krisis berikutnya.
@answer (a) Conceptualization: tugas = keselamatan pelanggan dan penyelamatan reputasi. Monitoring: antisipasi eskalasi liputan/review dan dinas kesehatan, sekaligus peluang tampil transparan. (b) Goal: memulihkan kepercayaan publik terhadap keamanan restoran. (c) Tanggung jawab pada korban, koordinasi dengan dinas kesehatan, komunikasi hasil investigasi + perbaikan SOP dapur, dan evaluasi respons untuk panduan ke depan.
@uses w1-mbo
@end
@example Susun goal kampanye yang measurable :: Kasus latihan
@soal
ARUNIKA, brand fashion lokal, kena isu "bahan cepat rusak" di media sosial. Manajemen minta goal kampanye PR dalam satu minggu.
(a) Tulis goal yang relevant dan measurable.
(b) Petakan goal itu ke 6 tahap MBO.
@step Susun goal yang measurable :: Planning di MBO minta hasil yang relevant dan measurable. "Perbaiki citra" nggak bisa diukur. Contoh yang bisa: kembalikan rating marketplace dari 3,8 ke 4,3 dalam 6 bulan lewat program garansi jahitan 1 tahun + konten transparansi pabrik.
@step Petakan 4 tahap awal :: Conceptualization: tugas = pulihkan kualitas yang dipersepsikan. Monitoring: tantangan = konten lama bisa viral ulang; peluang = tren #supportlocal. Planning: target rating 4,3 + 3 konten transparansi per bulan. Organization and coordination: tim QC, tim konten, admin marketplace satu komando.
@step Petakan administration + evaluation :: Administration: jadwal mingguan, budget garansi dan produksi konten. Evaluation: cek rating tiap bulan, bandingkan dengan baseline 3,8, laporkan sebagai accountability dan bahan kampanye berikutnya.
@answer (a) Contoh goal: naikkan rating marketplace 3,8 ke 4,3 dalam 6 bulan via garansi jahitan 1 tahun dan konten transparansi pabrik (3 konten/bulan). (b) Conceptualization = pulihkan persepsi kualitas; Monitoring = waspadai viral ulang, manfaatkan #supportlocal; Planning = target rating + output konten; Organization and coordination = satu komando QC-konten-marketplace; Administration = jadwal + budget; Evaluation = pantau rating bulanan sebagai accountability dan panduan berikutnya.
@uses w1-mbo
@end

@topic w1-corp :: Apa itu Corporation :: Definisi corporation, indikasi menjalankan corporate franchise, syarat dokumen, dan bankruptcy.
@intro
- Corporation = korporasi, joint stock company, real estate trust (Real Estate Trust Act), financial corporation, bank, dan asosiasi bisnis lain.
- Termasuk juga LLC dan partnership yang dikenakan pajak sebagai corporation (Internal Revenue Code).
- Corporation menjalankan corporate franchise = minta diperlakukan sebagai legal entity / person.
- Indikasinya: daftar di Public Regulation Commission, daftar di agensi regulasi negara bagian, tunjuk registered agent, tunjuk agen buat jalanin aktivitas di negara bagian, punya properti di negara bagian, daftar trade names.
- Dokumen wajib ada: Articles of Incorporation, bylaws, financial statements, notulen rapat 3 tahun terakhir, laporan ke shareholder 3 tahun terakhir, share register (nggak boleh lebih tua 1 tahun, berisi nama/alamat tiap pemegang saham + jumlah dan kelas sahamnya), catatan tanggal terbit saham, salinan kontrak, shareholder control agreements.
- Bankruptcy: dana yang diinvestasikan (beli saham) = aset perusahaan, bisa disita saat insolven. Limited liability bikin investor berani.
@concept w1-corporation :: Corporation :: Badan yang mencakup corporations, joint stock companies, real estate trusts (Real Estate Trust Act), financial corporations, bank, dan asosiasi bisnis lain — termasuk LLC dan partnership yang dikenai pajak sebagai corporation menurut Internal Revenue Code.
@concept w1-corporate-franchise :: Corporate franchise :: Corporation menjalankan corporate franchise saat minta diperlakukan sebagai legal entity/person menurut hukum negara bagian. Indikasinya antara lain: mendaftar ke Public Regulation Commission / agensi regulasi, menunjuk registered agent, menunjuk agen, memiliki properti di negara bagian, mendaftarkan trade names.
@concept w1-limited-liability :: Limited liability dan bankruptcy :: Dana yang diinvestasikan langsung ke perusahaan (misal beli saham) jadi aset perusahaan dan bisa disita saat insolvensi — begitu juga real estate, equipment, machinery, investasi atas nama institusi, dan barang produksi yang belum terjual. Tanpa limited liability sebagai preseden hukum, banyak investor ogah pegang ekuitas perusahaan.
@trap Semua usaha = corporation :: Salah. Warung kelontong atau usaha perseorangan yang nggak daftar sebagai badan hukum dan nggak menjalankan corporate franchise BUKAN corporation. Tesnya: apakah dia minta diperlakukan sebagai legal entity dan ada indikasi franchise (daftar regulator, registered agent, dst).
@example Apakah ini corporation? :: Kasus latihan
@soal
Empat entitas di Indonesia. Mana yang paling sesuai definisi corporation dari slide?
| Entitas | Fakta |
| PT Nusa Karya | Terdaftar, punya saham, tunjuk registered agent |
| Warung Bu Sari | Usaha perseorangan, izin usaha toko |
| Koperasi Warga Sejahtera | Badan hukum koperasi, anggota warga |
| CV Mitra Abadi | Partnership, kena pajak sebagai corporation |
(a) Klasifikasi berdasarkan definisi corporation.
(b) Kasih satu indikasi corporate franchise untuk PT Nusa Karya.
@step Terapkan definisi mentah-mentah :: Slide: corporation mencakup corporations, joint stock companies, real estate trusts, financial corporations, bank, asosiasi bisnis lain, DAN LLC/partnership yang dikenai pajak sebagai corporation.
@step Entitas per entitas :: PT Nusa Karya = corporation jelas (terdaftar + saham + registered agent). Warung Bu Sari = bukan (usaha perseorangan, tanpa badan hukum). Koperasi = asosiasi, tapi bukan korporasi dalam arti slide. CV Mitra Abadi = partnership YANG KENA PAJAK SEBAGAI CORPORATION → masuk definisi slide!
| Entitas | Corporation? | Alasan |
| PT Nusa Karya | Ya | corporation terdaftar + saham |
| Warung Bu Sari | Tidak | usaha perseorangan |
| Koperasi | Tidak | bukan asosiasi BISNIS, tidak menjalankan corporate franchise |
| CV Mitra Abadi | Ya | partnership taxed as corporation |
@step Indikasi corporate franchise (b) :: Dari daftar slide: mendaftar ke regulator (Public Regulation Commission / agensi regulasi), menunjuk registered agent untuk penerimaan proses hukum, memiliki properti, atau mendaftarkan trade names. PT Nusa Karya sudah tunjuk registered agent → itu indikasinya.
@answer (a) PT Nusa Karya ya; Warung Bu Sari tidak; Koperasi tidak (bukan asosiasi bisnis dan tidak menjalankan corporate franchise — beda dari "other business associations" yang masuk definisi slide); CV Mitra Abadi ya karena partnership yang dikenai pajak sebagai corporation ikut masuk definisi. (b) Menunjuk registered agent untuk menerima service of legal process atas nama perusahaan — salah satu indikasi exercise of corporate franchise.
@uses w1-corporation, w1-corporate-franchise
@end
@example Aset yang bisa disita saat bankruptcy :: Slide W1 · Mini case
@soal
PT Tekstil Mandiri insolven. Ada daftar aset dan klaim:
• Uang hasil penjualan saham ke investor (Rp10 M).
• Gedung pabrik dan mesin jacquard.
• 12.000 lembar kain jadi yang belum terjual.
• Rumah pribadi direktur (atas nama pribadi).
(a) Mana yang bisa disita dan dilikuidasi?
(b) Kenapa limited liability penting buat investor?
@step Klasifikasi aset perusahaan vs pribadi :: Slide: dana yang diinvestasikan langsung (beli saham) = aset perusahaan; plus real estate, equipment, machinery, investasi atas nama institusi, dan barang produksi yang belum terjual — semuanya bisa disita dan dilikuidasi. Rumah pribadi direktur BUKAN aset perusahaan.
| Item | Status |
| Uang saham Rp10 M | Aset perusahaan — bisa disita |
| Gedung + mesin | Real estate + machinery — bisa disita |
| 12.000 lembar kain | Goods produced not sold — bisa disita |
| Rumah pribadi direktur | Di luar jangkauan likuidasi |
@step Jelaskan logika limited liability (b) :: Dana investor sudah "menyatu" dengan perusahaan — hilang kalau perusahaan ambruk. Tapi kekayaan pribadi investor aman. Slide bilang: tanpa limited liability sebagai preseden hukum, banyak investor ogah punya ekuitas di perusahaan.
@step Antisipasi pertanyaan jebakan :: Jangan tulis "semua aset direktur ikut disita" — itu salah kaprah. Yang disita cuma yang jadi milik/dipegang perusahaan.
@answer (a) Uang saham Rp10 M, gedung pabrik, mesin jacquard, dan 12.000 lembar kain jadi bisa disita dan dilikuidasi; rumah pribadi direktur tidak. (b) Karena dana yang sudah diinvestasikan memang jadi aset perusahaan (bisa hilang), limited liability menjaga harta pribadi investor — tanpa jaminan ini investor enggan membeli ekuitas perusahaan.
@uses w1-limited-liability, w1-corporation
@end

@topic w1-comm :: Komunikasi sebagai Tanggung Jawab Strategis :: Corporate communication itu cara berpikir strategis, bukan cuma produksi materi kampanye.
@intro
- Manajemen senior sering lihat komunikasi cuma sebagai fungsi taktis: slogan, press conference, trade show, kampanye promosi.
- Padahal corporate communication = cara berpikir strategis dan proses pengambilan keputusan.
- Yang terlibat: communication manager, CEO, dan executive directors area fungsional lain.
- Communication strategy turunan dari corporate strategy.
- Communication strategy harus selaras dengan core values (corporate culture) anggota organisasi.
- Keputusan strategis harus diterjemahkan ke communication strategy khusus untuk tiap kelompok stakeholder.
@concept w1-corp-comm :: Corporate communication :: Cara berpikir strategis dan proses pengambilan keputusan yang melibatkan communication manager, CEO, dan executive directors area fungsional lain — bukan sekadar produksi materi komunikasi.
@concept w1-comm-strategy :: Communication strategy :: Turunan (derivative) dari corporate strategy, selaras dengan core values/corporate culture organisasi. Keputusan strategis perusahaan diterjemahkan menjadi communication strategy khusus untuk tiap kelompok stakeholder.
@trap Direktur minta slogan = pekerjaan PR selesai :: Salah — itu baru fungsi taktis (persiapan dan produksi materi komunikasi: slogan, press conference, trade show, kampanye promosi). PR sejati ikut meja keputusan: communication strategy diturunkan dari corporate strategy dan core values perusahaan.
@example Slogan vs strategi :: Kasus latihan
@soal
CEO PT Bank Nusra minta ke tim: "Bikinin slogan baru yang ngena buat iklan, next week press conference, siapin booth trade show." Kamu communication manager-nya.
(a) Versi manajemen senior, komunikasi itu apa?
(b) Versi corporate communication yang benar itu apa?
(c) Siapa saja yang harus ada di meja pengambilan keputusan?
@step Jawab (a) dari slide :: Senior management cenderung melihat komunikasi sebagai fungsi taktis: program komunikasi + persiapan & produksi materi (concrete messages/slogan untuk audiens eksternal, press conference, trade show, kampanye promosi). Permintaan CEO itu persis daftar ini.
@step Jawab (b) — naik ke level strategi :: Corporate communication = strategic way of thinking dan proses pengambilan keputusan. Pertanyaan yang benar bukan "slogan apa?", tapi "strategy bank ini mau dikomunikasikan apa ke stakeholder mana?" — turunan dari corporate strategy dan selaras core values.
@step Jawab (c) — pemain di meja :: Slide nyebut: communication manager, CEO, dan executive directors dari area fungsional lain. Slogan baru harus melalui forum ini, baru diterjemahkan ke pesan per stakeholder.
@answer (a) Fungsi taktis: bikin slogan, gelar press conference, trade show, kampanye promosi. (b) Cara berpikir strategis dan proses keputusan yang menurunkan corporate strategy menjadi communication strategy per stakeholder, selaras core values. (c) Communication manager, CEO, dan executive directors area fungsional lain di organisasi.
@uses w1-corp-comm, w1-comm-strategy
@end
@example Terjemahkan strategi ke tiap stakeholder :: Kasus latihan
@soal
Strategi korporat ARUNIKA tahun ini: "pindah 100% ke bahan ramah lingkungan dalam 2 tahun." Core values: transparansi dan keberlanjutan.
(a) Terjemahkan strategi ini jadi communication strategy untuk 3 stakeholder berbeda: pelanggan, karyawan pabrik, dan pemasok kain.
(b) Kenapa satu pesan universal buat semua stakeholder itu keliru?
@step Ambil prinsipnya dulu :: Slide: strategic decisions perlu diterjemahkan menjadi communication strategy spesifik untuk VARIOUS stakeholder groups, dan harus selaras core values (transparansi + keberlanjutan).
@step Terjemahkan per stakeholder :: Pelanggan: cerita perjalanan bahan + harga jujur (transparansi). Karyawan pabrik: pelatihan material baru + jaminan tidak PHK (keberlanjutan kerja). Pemasok: kontrak jangka panjang dengan standar sertifikasi bahan.
| Stakeholder | Pesan inti | Selaras value |
| Pelanggan | Jejak bahan transparan | Transparansi |
| Karyawan pabrik | Pelatihan + kepastian kerja | Keberlanjutan |
| Pemasok kain | Kontrak + sertifikasi | Keberlanjutan |

Pesan universal nggak menjawab kepentingan spesifik — communication strategy per group karena keputusan strategis sama tapi implikasinya beda-beda.
@answer (a) Pelanggan: transparansi jejak bahan dan harga; karyawan: pelatihan material baru plus jaminan kerja; pemasok: kontrak jangka panjang dengan standar sertifikasi. (b) Karena tiap kelompok stakeholder punya kepentingan berbeda — keputusan strategis yang sama harus diterjemahkan jadi communication strategy berbeda per kelompok.
@uses w1-comm-strategy, w1-stakeholders

@topic w1-components :: Komponen PR dan Speech Acts :: 6 pasangan komponen PR (dyad/collectivity dst) + 3 speech acts versi Marshak.
@intro
- Komponen PR pakai 6 pasangan: dyad/collectivity, inside/outside, intervention/investigation, analysis/synthesis, skills/theory, method/discipline.
- Dyad = komunikasi dua orang (surat, laporan, wawancara). Collectivity = satu ke banyak / grup / grup ke grup.
- Inside = komunikasi dalam organisasi. Outside = anggota organisasi ngobrol dengan pihak luar.
- Intervention = komunikasi untuk capai tujuan organisasi. Investigation = studi fenomena buat dipahami.
- Analysis = bedah kecil (micro). Synthesis = gabung jadi gambaran utuh (macro).
- Skills = craft. Theory = prinsip yang sistematis, menjelaskan dan memprediksi.
- Method = teknik komunikasi. Discipline = bidang studi yang koheren.
- Marshak speech acts: tool-talk, frame-talk, mythopoetic talk.
@concept w1-components :: Komponen public relations :: Enam pasangan yang membentuk PR: dyad/collectivity, inside/outside, intervention/investigation, analysis/synthesis, skills/theory, method/discipline.
@concept w1-speech-acts :: Marshak speech acts :: Tiga jenis bicara "big picture": tool-talk (diskusi penetapan tujuan dan pemberian arahan tugas), frame-talk (menafsirkan makna peristiwa, sifatnya interpretive), mythopoetic talk (tokoh korporasi mengomunikasikan visinya).
@vars
Tool-talk :: diskusi goal setting, memberi arahan tugas
Frame-talk :: menerjemahkan makna peristiwa, interpretive
Mythopoetic talk :: figur korporat menyampaikan visi
@slide w1-25
@trap "Myothopoetic talk" :: Slide nulis "Myothopoetic" — ejaan yang benar mythopoetic (bicara visi dari figur korporat). Di ujian tulis maknanya yang penting: komunikasi visi, bukan ejaannya.
@example Klasifikasi 6 komponen :: Kasus latihan
@soal
PT Logistik Andalan. Klasifikasi tiap kegiatan ke komponen yang tepat:
• HRD mewawancarai kandidat kurir.
• CEO presentasi kinerja di depan 300 karyawan (town hall).
• Tim riset mempelajari kenapa keluhan pelanggan naik.
| Kegiatan | Pilihan |
| Wawancara kandidat | dyad / collectivity / inside / outside |
| Town hall CEO | dyad / collectivity |
| Riset keluhan | intervention / investigation |
(a) Tentukan jawaban tiap baris + kasih alasan singkat.
@step Wawancara = dyad :: Dyad = komunikasi antara DUA orang, contoh formatnya memang letters, reports, dan interviews. Wawancara HRD-kandidat pas dua orang → dyad.
@step Town hall = collectivity :: Collectivity = komunikasi satu-ke-banyak (public communication), group (meetings, conferences), atau group-ke-group. CEO bicara ke 300 karyawan = one-to-many → collectivity.
@step Riset keluhan = investigation :: Intervention = perilaku komunikasi untuk mencapai tujuan organisasi; investigation = studi fenomena komunikasi organisasi untuk memahami dan mendeskripsikan cara kerjanya. Riset keluhan dipelajari supaya dipahami → investigation. (Catatan: kalau HRD wawancara kandidat itu inside dyad; risetnya investigation — dua komponen bisa dipakai beda pada kegiatan berbeda.)
@answer (a) Wawancara kandidat = dyad (dua orang, format interview). Town hall CEO = collectivity (one-to-many). Riset keluhan = investigation (mempelajari fenomena untuk memahami, bukan mengejar target).
@uses w1-components
@end
@example Speech acts di rapat tahunan :: Kasus latihan
@soal
Tiga kutipan dari rapat tahunan PT Gudang Rakyat:
• Direktur operasional: "Target Q3: kurangi waktu kirim rata-rata jadi 24 jam — tim fleet, jalan."
• Komisaris: "Kenaikan harga bahan bakar itu bukan kabar buruk; ini tanda kita harus serius pindah ke armada listrik."
• Founder: "Saya mimpi sepuluh tahun lagi setiap desa di Indonesia terima paket hari yang sama."
(a) Identifikasi speech act tiap kutipan + alasan.
@step Kenali pola tiap tipe :: Tool-talk = goal setting + arahan tugas. Frame-talk = menerjemahkan makna peristiwa (interpretive). Mythopoetic talk = figur korporat bicara VISI. Cocokkan substansi kutipan, bukan panjangnya.
@step Kutipan per kutipan :: Direktur operasional kasih target dan arahan tugas ke tim fleet → tool-talk. Komisaris menafsirkan ulang makna kenaikan BBM → frame-talk. Founder bicara mimpi jangka panjang → mythopoetic talk.
| Kutipan | Speech act | Penanda |
| Target Q3 + arahan tim | Tool-talk | goal setting, task of directions |
| Makna kenaikan BBM | Frame-talk | deciphering meaning, interpretive |
| Mimpi 10 tahun | Mythopoetic talk | figur menyampaikan visi |
@step Uji dengan lawannya :: Kalau kutipan pertama dibalik jadi "apa arti Q3 buat kita?" dia akan jadi frame-talk. Uji lawan seperti ini bikin batas tipe nggak kabur.
@answer (a) Direktur operasional = tool-talk (goal setting dan pemberian arahan); komisaris = frame-talk (menafsirkan makna peristiwa); founder = mythopoetic talk (figur korporat mengomunikasikan visi).
@uses w1-speech-acts
@end
